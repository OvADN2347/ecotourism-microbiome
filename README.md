Ecotourism Microbiota Pipeline
Overview

This repository contains a reproducible workflow for processing and analyzing environmental microbiome sequencing data generated from:

16S rRNA (Bacteria)
16S rRNA (Archaea)
ITS (Fungi)

The workflow is divided into two independent stages:

Sequence preprocessing and taxonomic assignment (Linux HPC)
Statistical analyses and visualization (Windows + R)

This separation simplifies installation and avoids dependency issues on HPC clusters.
